# Mercado Sabanero - Módulo de Liquidación

Este proyecto implementa la lógica de negocio para liquidar compras en Mercado Sabanero, utilizando Desarrollo Guiado por Pruebas (TDD). No incluye base de datos ni interfaz gráfica. El inventario externo se simula mediante un Doble de Prueba (Mock).

## Tecnologías Utilizadas
* **Lenguaje:** JavaScript (Node.js)
* **Framework de Pruebas:** Jest
